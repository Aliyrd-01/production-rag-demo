About this RAG

Production  MS MARCO  130K passages

Dataset: Microsoft MAchine Reading COmprehension — 130K passages chunked from first 150K corpus lines. Covers general knowledge, medicine, science, law, and everyday topics.

Architecture: Text query → contextualize (if history) → hybrid dense+sparse search → RRF fusion → CrossEncoder rerank → LLM generation with citations → faithfulness judge
